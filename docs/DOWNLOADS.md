# Загрузки и разновидности наборов

## Компактный набор из GitHub Releases

`Drehmal_RU_Patch.zip` содержит установщик перевода, готовые данные, русский ресурспак и переносимый Python для Windows x64. Он работает **поверх уже установленного оригинального мира** обеих редакций.

В нём нет карты, модов, Minecraft, Java или Fabric. Поэтому для нового прохождения сначала выполните [базовый](INSTALL_BASE.md) или [DLC-гайд](INSTALL_DLC.md), а потом примените перевод. Это позволяет скачивать оригиналы непосредственно у авторов.

## Полные офлайн-наборы

Отдельно были подготовлены:

| Файл | Состав | Размер |
|---|---|---|
| `Drehmal_RU_Installer.zip` | Оригинальная базовая карта 2.2.2f, модпак, ресурспак, моды, Python, перевод | около 4,4 ГБ |
| `Drehmal_DLC_RU_Installer.zip` | Специальный мир Primal Journey 3.0.6, модпак, ресурспак, моды, Python, перевод | около 4,67 ГБ |

Эти два больших архива **не загружены в этот Git-репозиторий и не входят в компактный релиз**. У GitHub лимит отдельного файла Release — менее 2 GiB ([документация](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)). Ссылки на скачивание больших офлайн-наборов здесь не заявляются, пока для них не опубликовано отдельное хранилище.

Если большой архив уже получен отдельно, используйте его собственный README и батник. Проверяйте SHA256 по файлу контрольных сумм, который поставляется вместе с конкретной публикацией. Контрольные суммы другой сборки после редакторских правок не совпадут.

## Исходники репозитория

Кнопка GitHub **Code → Download ZIP** скачивает исходники, а не готовый переносимый релиз. Из них можно запустить `python installer/existing.py` с установленным Python или собрать комплект через `tools/build.py`.
