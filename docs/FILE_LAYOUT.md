# Состав файлов карты и русификатора

[← К оглавлению](../README.md)

## Профиль Minecraft

```text
папка_игры/
├─ mods/                    моды именно выбранной сборки
├─ config/                  настройки модов и интерфейсов
├─ ldlib/                   дополнительные ресурсы/эффекты DLC
├─ resourcepacks/
│  ├─ оригинальный_пак.zip   модели, текстуры, звуки и исходные ресурсы
│  └─ Drehmal_RU.zip         русский язык и шрифты табличек
├─ saves/
│  └─ название_мира/
├─ options.txt              язык, порядок пакетов, настройки клиента
├─ Russian_Backup_.../      копии изменённых файлов при переводе готового мира
└─ Russian_Installation_Report.json
```

Профиль в Modrinth/Prism может храниться далеко от общей `.minecraft`. Ищите его через кнопку открытия папки в лаунчере. `mods`, `config` и `ldlib` относятся к профилю, а `datapacks`, `region` и `level.dat` — к миру.

## Сохранение мира

```text
мир/
├─ level.dat                свойства и состояние мира, список датапаков и др.
├─ level.dat_old            предыдущая копия level.dat
├─ session.lock             блокировка доступа к открытому миру
├─ datapacks/
│  ├─ hi_drehmal.zip         основная логика, сюжет, тексты; в DLC — его дополнения
│  ├─ emis.zip               функции и ресурсы соответствующего набора
│  ├─ bern.zip               функции и ресурсы соответствующего набора
│  └─ mael.zip               функции и ресурсы соответствующего набора
├─ region/                  блоки, местность, сундуки, таблички, командные блоки
├─ entities/                сущности, их имена, экипировка, торговля и предметы
├─ poi/                     точки интереса жителей; не словарь перевода
├─ data/                    scoreboard, command_storage и другие NBT-данные
├─ playerdata/              инвентари и состояние игроков по UUID
├─ advancements/            полученные игроками достижения
├─ stats/                   статистика игроков
├─ dimensions/              дополнительные измерения, включая minecraft/lodahr
├─ DIM-1/                   Нижний мир, если присутствует
└─ DIM1/                    Край, если присутствует
```

Состав зависит от редакции и состояния сохранения. Не удаляйте неизвестные файлы, считая их лишними. JSON в `advancements/` самого мира хранит прогресс игрока; определения названий и описаний достижений находятся **внутри датапаков** в `data/<namespace>/advancements/`.

`r.x.z.mca` — контейнер региона. Один регион объединяет до 32×32 чанков; файл может одновременно содержать важные для прохождения объекты и обычную территорию. Это не текстовый файл с одной репликой. Перевод нужно менять внутри нужных NBT-полей, а не заменять регион чужим файлом.

## Внутри датапака

```text
pack.mcmeta
data/
  <namespace>/
    functions/*.mcfunction
    advancements/*.json
    loot_tables/*.json
    predicates/*.json
    item_modifiers/*.json
    structures/*.nbt
    ...
```

Функции содержат как реплики (`tellraw`, `title`, `bossbar`), так и механику. Loot tables, item modifiers, структуры и команды выдачи могут хранить имена, описания и книги. Поэтому правка одного файла диалога не переводит автоматически все уже размещённые экземпляры предметов.

`bern`, `emis` и `mael` — имена отдельных архивов/пространств проекта, а не приглашение переименовать их на русский. Точные пути и ID сохраняют.

## Компактный набор из Releases

```text
Drehmal_RU_Patch/
├─ Install_RU.bat
├─ README_RU.txt
├─ installer/               движок и точка входа existing.py
├─ data/
│  ├─ translation_payload.json.gz
│  └─ Drehmal_RU.zip
├─ manifests/
│  ├─ base.json
│  └─ dlc.json
└─ runtime/                 переносимый Python в готовом Windows-релизе
```

Здесь нет оригинального мира: набор применяется к вашей копии. В сборке из исходников без `--runtime-zip` папка `runtime` отсутствует, и используется системный Python.

## Большой офлайн-установщик

В полном наборе находятся батник конкретной редакции, `install.py`, движок, манифест, перевод, ресурспак, runtime, оригинальные ZIP/`.mrpack` в `originals/` и файлы модов с именами по SHA512 в `downloads/`.

Имена в `downloads/` — контрольные суммы, а не имена модов. При установке пути `mods/<имя>.jar` и другие назначения берутся из `modrinth.index.json` внутри `.mrpack`.

Полный набор может собрать профиль с нуля. Компактный набор GitHub и папка исходников не равны этому многогигабайтному комплекту.
