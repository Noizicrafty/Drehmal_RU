Drehmal RU — компактный русификатор готового мира

1. Полностью распакуйте ZIP. Закройте Minecraft/сервер.
2. Запустите Install_RU.bat.
3. Выберите 1 — базовая Apotheosis 2.2.2f или 2 — Primal Journey 3.0.6.
4. Укажите папку мира с level.dat и папку игры с resourcepacks/mods/config.
5. Дождитесь сообщения «Готово», затем откройте мир заново.

Комплект переводит уже установленный мир. Для новой игры сначала установите
оригинальные моды, карту и ресурспак по гайду нужной редакции.
Это не Minecraft, не модпак и не конвертер базовой карты в DLC.

В готовом Windows x64-релизе Python включён. Сборка из исходников без runtime
использует установленный Python 3.11+. Minecraft Java 1.20.1, Java и Fabric
настраиваются отдельно в лаунчере.

Создаются резервные копии изменённых файлов в Russian_Backup_дата_время
в папке игры. Отчёт: Russian_Installation_Report.json.
Ошибка: installation_error.log. Не обходите блокировку открытого мира.

Подробные гайды, устройство файлов и редактирование перевода:
https://github.com/Noizicrafty/Drehmal_RU
