# Базовая Drehmal: Apotheosis — установка с нуля

[← К оглавлению](../README.md) · [Установка DLC](INSTALL_DLC.md)

Здесь «новая карта» — неизменённое стартовое сохранение **Apotheosis 2.2.2f**. Создание обычного мира по случайному сиду не создаст Drehmal.

## 1. Подготовьте игру

Нужны Minecraft Java 1.20.1, Java 17 или новее и лаунчер с поддержкой Fabric. Для проверенного набора используется Fabric Loader 0.16.14. Выделите игре примерно 6–8 ГБ памяти, если это позволяет объём RAM компьютера.

Создайте отдельный профиль. Не смешивайте его моды с произвольной другой сборкой.

## 2. Установите оригинальную сборку

На [официальной странице Drehmal](https://www.drehmal.net/downloads) доступны авторский установщик, модпак, мир и ресурспак.

Удобный ручной путь:

1. Скачайте [модпак 2.2.2f](https://modrinth.com/modpack/drehmalmc/version/PlB74b6H).
2. Импортируйте `.mrpack` как новый профиль в Modrinth App или Prism Launcher. Это устанавливает выбранные автором моды и настройки; сам файл `.mrpack` не кладут в `mods`.
3. После завершения откройте папку созданного профиля через лаунчер.
4. Скачайте **World File** с [официальной страницы](https://www.drehmal.net/downloads).
5. Создайте в `saves` папку, например `Drehmal`, и распакуйте туда мир. Проверочный путь: `saves/Drehmal/level.dat`. Рядом должны находиться `datapacks`, `region` и другие файлы сохранения.
6. Проверьте наличие оригинального ресурспака. Если его нет после импорта модпака, скачайте **Resource Pack** с той же страницы и положите ZIP без распаковки в `resourcepacks` профиля.

Авторский установщик с официального сайта — альтернативный путь: после его завершения найдите созданную им папку игры и установленный мир. Для русификации нужны именно эти пути.

## 3. Установите русский перевод

До первого входа в мир примените [компактный русификатор](INSTALL_EXISTING.md): выберите редакцию **base**, укажите `saves/Drehmal` и папку профиля. Дождитесь завершения.

Это та же операция перевода, что для существующего сохранения, но мир ещё не содержит вашего прогресса. Не копируйте сюда целиком чей-то уже пройденный NEW: в этом случае вы получите и чужое состояние игры.

## 4. Запустите карту

1. В лаунчере выберите созданный профиль Minecraft 1.20.1/Fabric.
2. Проверьте папку игры и выделенную память.
3. Включите оригинальный ресурспак, а русский пакет расположите с более высоким приоритетом. Установщик уже добавляет русский пакет в настройки.
4. Выберите русский язык и войдите в установленный мир.

Не создавайте вместо него новое сохранение кнопкой «Создать мир». Механика, строения и сюжет уже находятся в скачанной карте.

## Полный офлайн-набор

Ранее подготовленный `Drehmal_RU_Installer.zip` содержит оригиналы, моды и Python. Если у вас уже есть этот большой архив, полностью распакуйте его, запустите **`Install_Drehmal_RU.bat`**, выберите режим **1 — новая установка** и укажите **пустую папку игры**. Мир появится в `saves/Drehmal_RU`.

В том офлайн-установщике режим **2** означает перевод готового мира. В компактном GitHub-наборе `Install_RU.bat` выбор **1/2** обозначает **base/DLC**. Не путайте два интерфейса.

Полный офлайн-набор не устанавливает сам Minecraft, Java или лаунчер и не создаёт автоматически профиль в каждом стороннем лаунчере. Готовую папку игры нужно указать в своём лаунчере. О доступности больших архивов — [здесь](DOWNLOADS.md).
