# Primal Journey 3.0.6 (DLC) — полная установка

[← К оглавлению](../README.md) · [Базовая карта](INSTALL_BASE.md)

Primal Journey — отдельная неофициальная расширенная сборка. Для ветки 3.0.4+ нужен **специальный мир Primal Journey** из папки, указанной в авторском гайде. Обычный World File с сайта Drehmal не заменяет его.

## 1. Подготовьте профиль

Проверенная конфигурация: Minecraft Java 1.20.1, Fabric Loader 0.16.10, Java 17 или новее; ориентир по памяти — 6–8 ГБ.

1. Скачайте [Primal Journey 3.0.6 на Modrinth](https://modrinth.com/modpack/drehmal-apotheosis-2.2-dlc/version/w7b6mFgs).
2. Импортируйте `.mrpack` в Modrinth App или Prism Launcher как **новый отдельный профиль**.
3. Дождитесь установки модов и настроек, затем откройте папку профиля через лаунчер.

`.mrpack` — описание сборки и её дополнительные файлы, а не мод для папки `mods`. Не обновляйте включённые моды по одному: авторский набор версий подобран совместно.

## 2. Добавьте специальную карту и ресурспак

Откройте [Primal Journey Files](https://drive.google.com/drive/folders/1KLIzWxiu9YrNrDYrDAqtvorH2-0-Q2-n). Ссылка также находится в `Installation_Guide.pdf`, поставляемом с модпаком.

Скачайте:

- `Drehmal APOTHEOSIS Primal Journey.zip` — специальное сохранение;
- `Drehmal Resource Pack v2.2.2f.zip` — оригинальный ресурспак.

Распакуйте мир в `saves/Primal Journey` профиля. Проверочный путь: `saves/Primal Journey/level.dat`; в этой же папке должен находиться `datapacks/hi_drehmal.zip`. ZIP ресурспака положите **без распаковки** в `resourcepacks`.

Не переносите мир из базового гайда, не подменяйте датапаки чужим `hi_drehmal.zip` другой версии и не добавляйте DLC к начатому базовому прохождению этим русификатором. Установка дополнения и перевод — разные операции. Для нового прохождения берите специальный исходный мир DLC.

## 3. Примените перевод

Закройте игру и выполните [инструкцию для существующего мира](INSTALL_EXISTING.md), выбрав **dlc**. Укажите новый мир Primal Journey и папку его профиля. Даже если вы ещё не входили в мир, это правильный режим для компактного набора: исходная карта уже установлена на диске.

Перевод не переносит из тестового NEW инвентарь, постройки, пройденные задания или открытые башни.

## 4. Первый запуск

Выберите профиль DLC в лаунчере и проверьте, что:

- используется его отдельная папка игры;
- установлены моды и настройки из `.mrpack`, включая `config` и `ldlib`;
- оригинальный ресурспак включён, а `Drehmal_RU.zip` имеет более высокий приоритет;
- выбран язык `ru_ru` и выделено достаточно памяти.

Откройте скачанный мир. Для проверки перевода подойдут книги, диалоги NPC, чат на базе и меню станции улучшения. Если отсутствуют предметы или появляются ошибки неизвестных ID, сначала сверяйте моды и версию мира: это не исправляется изменением языка.

## Полный офлайн-набор

Если у вас есть большой `Drehmal_DLC_RU_Installer.zip`, распакуйте его и запустите **`Install_DLC_RU.bat`**. Режим **1** собирает новый профиль в **пустой папке игры**, режим **2** переводит готовый мир DLC. Новое сохранение находится в `saves/Drehmal_Primal_Journey_RU`.

Внутри полного набора уже есть карта, ресурспак, моды, конфигурации и Python. Minecraft, Java, Fabric и сам лаунчер настраиваются отдельно. Эти многогигабайтные архивы не входят в исходники репозитория; см. [загрузки](DOWNLOADS.md).

## Если это сервер

Используйте авторскую серверную конфигурацию: клиентскую папку `mods` нельзя без проверки целиком копировать на сервер. Инструкция автора отдельно требует соответствующие `config` и `ldlib` на клиенте и сервере.

Остановите сервер, переведите копию его мира на Windows и верните её до возобновления игры. Каждый клиент должен получить оригинальный и русский ресурспаки. Встроенные в мир русские реплики будут видны всем игрокам, независимо от их языка интерфейса.
