# Установка на существующий мир

[← К оглавлению](../README.md)

Этот способ переводит уже установленную базовую карту или DLC. Он не устанавливает моды и не обновляет версию карты. Постройки, инвентарь, задания и прогресс не заменяются стартовым сохранением.

## Подготовка

1. Определите редакцию: Apotheosis 2.2.2f или Primal Journey 3.0.6. Для DLC нельзя выбирать базовую редакцию.
2. В лаунчере откройте папку **именно этого профиля**. Не используйте общую `.minecraft`, если сборка запускается из отдельной папки.
3. Найдите мир: `папка_игры/saves/название_мира/level.dat`.
4. Закройте игру. Для сервера сначала выполните штатное сохранение и полностью остановите сервер.
5. Скопируйте весь мир в отдельное место. Автоматическая копия изменяемых файлов дополнительно создаётся установщиком, но не заменяет независимый снимок всего сохранения.

Пример структуры:

```text
D:\Minecraft\Drehmal\            ← папка игры
  mods\
  config\
  resourcepacks\
  saves\
    Мой мир\                      ← папка мира
      level.dat
      datapacks\
      region\
```

## Установка из Releases

1. Скачайте `Drehmal_RU_Patch.zip` из [Releases](https://github.com/Noizicrafty/Drehmal_RU/releases).
2. Распакуйте **весь архив**, сохранив подпапки. Не запускайте BAT прямо из окна архиватора.
3. Запустите `Install_RU.bat`.
4. Выберите `1` для Apotheosis или `2` для Primal Journey. В этом компактном наборе числа обозначают **редакции**, а не режимы полного офлайн-установщика.
5. Укажите папку мира, в которой непосредственно лежит `level.dat`.
6. Укажите папку игры с `mods`, `config`, `saves` и `resourcepacks`. Для мира в `saves` предложенный путь обычно уже правильный.
7. Дождитесь сообщения «Готово». Обработка регионов может занять несколько минут.

Установщик изменяет тексты в датапаках и NBT, добавляет `resourcepacks/Drehmal_RU.zip`, выбирает `ru_ru` в `options.txt` и добавляет русский ресурспак в конец списка пакетов, то есть с более высоким приоритетом. Оригинальный ресурспак оставьте включённым: русский пакет дополняет его.

Если оригинальный ресурспак ещё не установлен, скачайте его по гайду своей редакции и включите перед русским пакетом. Компактный русификатор сам оригинал не скачивает.

## Запуск из исходников / командной строки

Из корня клонированного репозитория, с Python 3.11+:

```powershell
python installer/existing.py --edition base --world "D:\Minecraft\Drehmal\saves\Мой мир" --target "D:\Minecraft\Drehmal"
```

Для DLC:

```powershell
python installer/existing.py --edition dlc --world "D:\Minecraft\PrimalJourney\saves\Мой мир" --target "D:\Minecraft\PrimalJourney"
```

`--world` — сохранение; `--target` — папка игры. Это разные пути. Для набора из Releases можно передать те же параметры батнику.

## После установки

Откройте мир заново. Проверьте книгу, разговор с NPC, чат на базе, меню улучшения и русские подписи. Перезагрузка ресурсов `F3+T` обновляет ресурспак, но сама по себе не заменяет повторный вход в мир после изменения сохранения.

Уже полученные предметы и книги переводятся, если их исходные тексты распознаны. Неизвестные, авторские и существенно изменённые книги могут остаться без перевода: не стоит подменять их случайным похожим текстом.

В папке игры появляется `Russian_Installation_Report.json`. В нём указаны обработанный мир, статистика и путь резервной копии.

## Восстановление

Копии находятся в `Russian_Backup_ГГГГММДД_ЧЧММСС` внутри папки игры. При обычной структуре они повторяют пути профиля: например, `saves/Мой мир/region/...`, `resourcepacks/...` и `options.txt`.

Закройте игру и скопируйте файлы из нужной резервной копии обратно по тем же относительным путям. Если мир находится вне папки игры, его копии могут лежать в подпапке `world/`: сверяйте путь с отчётом. Возвращайте региональные файлы из одной согласованной копии, не смешивая разные даты. Снимок, сделанный до установки, вернёт и прогресс на тот момент.

## Ошибки

| Сообщение / симптом | Что проверить |
|---|---|
| Нет `level.dat` | Выбрана родительская папка или лишний уровень вложенности |
| Нет `datapacks/hi_drehmal.zip` | Это другая карта, обычный мир Minecraft или не полностью распакованный оригинал |
| Другая редакция мира | Перепутаны base и DLC; перевод не конвертирует редакции |
| Мир открыт в Minecraft | Закройте игру/сервер; не обходите блокировку удалением `session.lock` |
| Повреждены данные русификатора | Скачайте и распакуйте полный набор заново; после собственных правок пересоберите контрольные суммы |
| Русский текст есть, но модели/текстуры отсутствуют | Нужны оригинальный ресурспак и моды соответствующей сборки |
| Ничего не изменилось в игре | Проверьте профиль, путь мира, отчёт, язык и порядок ресурспаков; полностью перезайдите |

Подробности исключения сохраняются в `installation_error.log` рядом с набором/в корне репозитория. Перед публикацией лога удалите из него ненужные личные пути.
