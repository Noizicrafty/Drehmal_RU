# Drehmal RU

Русский перевод **Drehmal: Apotheosis 2.2.2f** и **Primal Journey 3.0.6** для Minecraft Java 1.20.1. Перевод перенесён из вычитанного мира NEW: книги, диалоги, сообщения чата, меню улучшения предметов, достижения, подписи и ресурспак. Имена персонажей, названия городов и вымышленные слова сохраняются в оригинале.

Это отдельный неофициальный проект. Primal Journey — неофициальное дополнение к Drehmal, ранее называвшееся DLC. Перевод может содержать ошибки; исправления принимаются через Issues и Pull Requests.

## Скачать русификатор

Откройте [Releases](https://github.com/Noizicrafty/Drehmal_RU/releases) и скачайте `Drehmal_RU_Patch.zip`. Это небольшой набор **для перевода готового мира**: он не содержит карту, Minecraft и моды. Один установщик поддерживает обе редакции; редакция выбирается при запуске.

1. Полностью распакуйте ZIP.
2. Закройте Minecraft или остановите сервер.
3. Запустите `Install_RU.bat` и укажите редакцию, папку мира с `level.dat` и папку игры.
4. При установке на готовый мир сохраняются резервные копии изменяемых файлов.

Для новой игры сначала установите оригинальную базовую карту или специальный мир DLC по соответствующему гайду, затем примените этот набор **до первого входа**. «С нуля» означает чистый оригинальный мир Drehmal, а не обычный мир, сгенерированный Minecraft.

## Совместимость

| Редакция | Minecraft | Fabric Loader в проверенном наборе | Оригиналы |
|---|---|---|---|
| Apotheosis 2.2.2f | Java 1.20.1 | 0.16.14 | [Drehmal](https://www.drehmal.net/downloads), [набор модов](https://modrinth.com/modpack/drehmalmc/version/PlB74b6H) |
| Primal Journey 3.0.6 | Java 1.20.1 | 0.16.10 | [Modrinth](https://modrinth.com/modpack/drehmal-apotheosis-2.2-dlc/version/w7b6mFgs), [специальный мир и ресурспак](https://drive.google.com/drive/folders/1KLIzWxiu9YrNrDYrDAqtvorH2-0-Q2-n) |

Для игры нужны Java 17 или новее и установленный Minecraft с Fabric. Ориентир по памяти — 6–8 ГБ. Приведены версии проверенных сборок; будущие версии карты автоматически совместимыми не считаются.

Батник и автоматическая установка рассчитаны на **Windows x64**. В релиз включён переносимый Python; при работе из исходников нужен Python 3.11+ (проверено на 3.13). Автоматический установщик не настраивает лаунчер, не устанавливает Minecraft, Java или Fabric и не превращает базовый мир в DLC.

## Что находится в репозитории

| Путь | Назначение |
|---|---|
| `docs/` | Пошаговые инструкции и результаты проверок |
| `installer/` | Установщик и движок изменения текстов без замены чанков целиком |
| `translation/text.json` | Общий словарь английский → русский |
| `translation/books/` | 427 подготовленных книжных вариантов с доступными для правки JSON-страницами |
| `translation/chat.json` | Контекстные переводы составных сообщений |
| `translation/strings.json`, `json_strings.json` | Точные и структурные замены текстовых компонентов |
| `translation/member_templates.json.gz` | Проверенные снимки отдельных переведённых файлов датапаков |
| `translation/overrides.json` | Пользовательские исправления с приоритетом при сборке |
| `resourcepack/` | Исходники русского языка и шрифтов табличек |
| `data/` | Готовые данные перевода и русский ресурспак |
| `manifests/` | Версии, источники и контрольные суммы |
| `tools/build.py` | Сборка обновлённого русификатора из исходников |

Оригинальные карты и моды скачиваются у авторов и в Git не включены. Многогигабайтные полные офлайн-наборы отличаются от небольшого русификатора в Releases; подробнее — [о загрузках](docs/DOWNLOADS.md).

## Быстрая сборка после исправлений

```powershell
python tools/build.py
```

Результат: `dist/Drehmal_RU_Patch.zip`. Без дополнительного параметра эта сборка использует установленный в системе Python. Включить переносимый runtime можно параметром `--runtime-zip`; подробности и порядок изменения приоритетных замен приведены в [гайде редактора](docs/EDIT_TRANSLATION.md).

## Что проверено

Проверены установка на отдельные чистые профили обеих редакций, резервные копии, повторное применение, отказ при выборе другой редакции, сохранение служебных имён и разделение шрифтов табличек и имён мобов. Проведена независимая сверка изменённых NBT-данных с оригиналами и проверка датапаков. Результаты находятся в [`docs/verification/`](docs/verification/).

Это техническая проверка, **не полное прохождение игры**. Отдельный запуск Minecraft при подготовке этих установщиков не выполнялся.
